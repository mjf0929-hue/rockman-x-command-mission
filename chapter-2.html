從 X 在地下醫療室醒來開始，一路寫到強哥（ワイルドジャンゴー）擊破。包含 PS2 專屬 X8 試玩鑰匙、史派達兩次事件、艾爾 ID、救 チーフR、200 秒自爆路線、三商店、所有現場道具與章後空中都市解鎖。

地下 999F空中都市史派達戰艾爾中央塔內部救 チーフR200 秒自爆強哥 Boss章後必做道具總表

Shaft 999F：醫療室醒來 → 螺旋通道

劇情後 X 在地下醫療室醒來。
角落女性 Reploid 是第一個商人；旁邊維修床可回滿 LE、サブタンク。你有滿錢，想收集就把現階段能買的道具各買一些。
地下商店商品：
ワクチンプログラム 80Z、アンチロック 80Z、フルリペア 240Z、リブート 500Z、メガファイア 160Z。
正常攻略會建議多買 メガファイア；你現在不缺戰力，但「商店有就收」的玩法仍可各買一份。
從醫療室唯一出口出去，進主通道後左轉。
右邊現在被 ディグレイバー 封住，那是破關後內容的方向，不是你走錯；第二章第一次來就是走左側。
沿螺旋走道一直往上，不要只衝門。
沿路依序拿：クリアビジョン、ワクチンプログラム、ビルドパワー。
也可以順手和路上居民對話；遊戲有「與居民對話 100 次」挑戰。
到 Air City Gate 後，前方被黃色施工 Reploid 擋住。
和他說話確認道路封閉，然後走他後方／右側的繞道進 Access Tower E-1。

Access Tower E-1：PS2 版別漏 X8 試玩鑰匙

這條通道基本是直線，但要掃左右。
取得：ゲインHYPER、タンクエナジー100。
看到左側小凹槽，一定撞紫色 Mystery Data。
PS2 版會拿到 X8トライアルキー，也就是《洛克人 X8》試玩版解鎖鑰匙。這個是 PS2 專屬，GameCube 沒有。
穿過下一扇門進 Air City East Square。

空中都市：East Square → 3rd Street → North Square

進 East Square 會播「X 被通緝」劇情。
劇情後可以和廣場居民說話。通往 Shopping Arcade 的路現在鎖著，不要在這裡繞半天。
走另一側主線通道，途中有 Save Point。
繼續前往 3rd Street。
3rd Street 一進去，左手邊有大型紫色公仔販賣機。
這台是 Treasure Token 類公仔機；PS2 版不走 GBA Treasure Radar 那套，但機台本身仍是重要地標。
穿過走廊到 North Square。
黑暗儲藏區沒有主線道具；再往另一扇門走會觸發賞金獵人史派達登場。

MINI BOSS：史派達（スパイダー）第一次戰鬥

LE1800弱點火屬性 150%
掉落／偷盜無；這場是劇情小 Boss，打幾回合後結束。
  • Counter Card：先架射擊防護；正常玩法用 X Fire 的 Charge Collider（格鬥型）拆。
  • Four Penalty：四連擊並降低能力。
  • Tri-Card：火／水／雷隨機屬性三連。
  • 正常玩法：防禦到 WE 100% → X Fire → Charge Collider。你現在 Lv.99 幾乎直接過。
這戰不需要打到死亡：史派達會在幾回合後撤退，屬於劇情過場。

史派達戰後：密碼機＋Power Charge

史派達離開後，進前方門到 Access Tunnel E-1 另一段。
左側會看到黃色 Password Machine。
這就是「密碼公仔」機台。本站另外有日版公仔密碼頁；不要用美版密碼混著輸。
同區把 3 個現場道具拿齊。
Power Charge、タンクエナジー50、100Z。
Power Charge 很重要。
消耗 30 WE，讓下一次攻擊增傷；連續充兩次可疊更高。你現在數值爆表不缺傷害，但它是正式收集。

繞過路障 → 艾爾（エール）事件

從通道出口回到 Air City Gate 的路障另一側。
右轉，沿上坡走；會進入較暗、地上有碎石的區域，路線會做一個明顯 U 型折返。
走到事件點，遇到艾爾。
他是 チーフR 的助手／反抗軍實際領導者之一。談話後把 エールのID 交給 X，讓你可以進中央塔內部區域。
プレオン Chaser 追來時，艾爾把 X 推進門後自爆。
這裡之後不能原路回他身邊，主線會強制進 Tower Base Access Tunnel。

中央塔內部：Access Tunnel → 維修區 → Base Security

Tower Base Access Tunnel 第一段。
ゲインHYPER、メガファイア。
第二段通道。
100Z、タンクエナジー∞（全能源槽補滿）。
進 Equipment Maintenance B。
兩組儲物櫃後面各藏一個：ビルドアーマー、ビルドスピード。這兩個很容易因為只看門而漏。
走標有上箭頭的門，沿螺旋往上到 Equipment Maintenance A。
左邊有 Save Point；西側房拿 100Z。主線走東側。
東側通道遇反抗軍士兵。
和他說話，他會拜託你救下一房的同伴。
進 Base Security Station，先打兩隻 プレオン Chaser。
打完救出人質，其中一人給你 セキュリティカード。
這房間是第二章核心補給站。
三位女商人販售道具、主／副武器、FM；角落坐著的 Reploid 可免費回滿 LE、サブタンク、Hyper。
別只買東西，兩側房也要搜。
西側：200Z。北側：ドメガファイア。

第二章三商店

分類商品
道具ワクチンプログラム 80Z、アンチロック 80Z、フルリペア 240Z、リブート 500Z、メガファイア 160Z
主武器Fire Buster 500Z、Guard Buster 500Z
副武器Fire Missile 1500Z、Micro Missile 300Z、Tomahawk 400Z
FMThunder Guard 500Z、Power+1 120Z、Armor+1 80Z、Shield+1 80Z、Speed+1 120Z、Virus Protection 80Z、Bind Protection 60Z、スペアボディ 1000Z、Analyzer 1000Z
正常攻略：Fire Buster 與 Thunder Guard 對章末強哥很有用。
你的玩法：錢滿了，建議商店當下直接各買一份，避免之後回頭確認「我到底有沒有收過」。

Data バックアップ 區：アイポイント → 史派達反水 → 救 チーフR

從補給站往上，進 Data バックアップ Room Hall A。
房間中央：タンクエナジー25。
先走左（西）側。
進下一小通道後再走左，拿 FM アイポイント（命中強化）。然後回岔路，改走右側前往 Hall B。
Hall A 一開始看到的右側主路此時鎖住。
先記住；等等 チーフR 啟動自爆逃生流程時，它會變成你的捷徑。現在不要在這裡找開關。
Hall B 觸發史派達事件。
史派達先把 X 擊倒，但看到 X 掉出的 エールのID；X 說明艾爾犧牲後，史派達改變立場，決定不替強哥做事。
史派達留下來擋兵，X 往前救 チーフR。
下一房固定戰：プレオン Spark ×2。打完救出 チーフR。
チーフR 得救後，強哥啟動中央塔自爆。
畫面出現約 200 秒計時。接下來不是原路慢慢散步，而是要照 チーフR 開的捷徑衝到 Command Room。

200 秒自爆：正確逃生路線

不用緊張：固定戰鬥時倒數會停止；真正會吃時間的是你走錯門、原地繞圈。你的 Lv.99 也能把三場固定戰瞬間處理。
救完 チーフR 後立刻原路回 Hall B。
第一場固定戰：プレオン Bitmaster ×2。
回 Hall A 後，改走剛才「鎖著」的右側門。
チーフR 會替你開。第二場固定戰：プレオン Chaser ×2。
到 Command Center Staff Room，計時期間先什麼都不要撿。
直接走東門進長走廊。
到 Base Entrance 後，立刻走左手門。
進 Base Gateway，再走正前方門。
到 Command Room，第三場固定戰。
プレオン Chaser ×2＋プレオン Spark ×1。
打完後調查房間中央的大紅按鈕。
自爆解除。這時才開始回頭撿剛才故意略過的東西。

解除自爆後：一定要回頭收，不要直接衝 Boss

Base Entrance 中央拿 タンクエナジー25。
東門是之後前往停機坪／強哥；先別走。
回 Command Center Staff Room。
開北門，固定戰 プレオン Bitmaster ×2；打完拿 タンクパーツ。
一路回到剛才救 チーフR 的 Data バックアップ Room。
穿過 チーフR 所在位置到後方，拿 100Z。
建議再回三商店最後補貨／補收集。
旁邊免費補給 NPC 可把 LE、サブタンク、Hyper 全回滿。正常攻略此時會準備 Fire Buster、Thunder Guard；你的數值則不必擔心戰力。
整理完再回 Base Entrance，走東門。
途經 Large Heliport Access Tunnel，先拿 バックアップ、タンクエナジー100，再進大門。

BOSS：強哥（ワイルドジャンゴー）

LE9000屬性雷；吸收雷傷、火傷 150%
固定掉落サブタンク、Thunder Buster可偷Thunder Guard、Protect+1
報酬500Z、1000 EXP
  • Shock Nail：雷屬性，可能 Virus。
  • Lightning Rod：雷屬性並降低／吸收速度。
  • Rolling Assault：高倍率單體衝擊。
  • ドメガサンダー：全體雷傷。
正常玩法：Fire Buster 打弱點；X WE 滿後 X Fire → Charge Collider。史派達本戰正式並肩作戰，他的 Hyper 期間可無敵。
你的玩法：不會輸，但如果你想「看完整 Boss 機制」，先用普通武器打幾回合再收掉。
打完必得：第二個 サブタンク＋Thunder Buster。史派達正式加入隊伍，第二章結束。

第二章結束後，先別急著找 チーフR 開 CH3

Air Bus 恢復→South Square→走廊 フィギュアコイン ×3→白色公仔機→Shopping Arcade→傳送站解鎖
中央塔大部分區域現在正式開放。
破關後用 Air Bus 到 South Square。
往城市主路走，第一段走廊旁有 3 個 フィギュアコイン。
旁邊是第一台白色一般公仔機，2 枚代幣抽 1 個公仔。
繼續走到 Air City Shopping Arcade。
這裡有完整道具店、武器店、綜合商人、FM 店，以及傳送站；從現在開始可以回已通關區域補收集。
中央塔還有「破關後特別封印區」，現在仍不能進。
地下 999F 一開始被 ディグレイバー 擋住的方向，就是日後的一部分；要全破主線後再處理。
如果你要 100%，現在就開始跑中央塔派遣。
中央塔派遣共有 33 項，不要只看主線影片。
