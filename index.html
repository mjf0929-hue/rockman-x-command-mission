你這次的玩法

角色一入隊就是高等大佬，但劇情、商店、武器、FM、公仔、寶箱都照正常流程自己拿。不開全武器、不強制全角色。

最重要的習慣

每破一章都回基地：商店看新貨 → 派遣收結果 → 補 FM → 再進下一章。很多 100% 漏項不是藏在迷宮，而是漏掉章節更新。

破關不等於結束

破關後拿中央鑰匙，才會開放特別封印區與一尾～九尾。你以前打完九尾，這次可以直接用清單確認有沒有漏收。

這次重玩總清單

完成 0 / 10

用法：每一章先看「不可漏」，再照流程跑。英文原名只放小字對照。
CH1

潛入基坎提斯！

舞台：拉格廢墟｜原名：Infiltrate Giga City!
艾克斯單獨行動→與傑洛會合→河馬型頭目→劇情分離
  • 前期先熟悉衝撞破壞場景物件，很多小道具藏在可破壞物附近。
  • 這章不用為了練等停留；你已經有滿等碼，重點改成把可拿的箱子與 FM 撿乾淨。
  • 章末劇情後，存檔再進下一段。
CH2

奪回中央塔

舞台：中央塔｜原名：Recapture Central Tower
新希望基地→中央塔→史派達加入→狂野強哥
  • 這章結束後，基地功能才真正展開：商店、傳送、派遣開始變得重要。
  • 之後每一章破完，都回來看商店有沒有新增武器／副武器／FM。
  • 別把「錢滿」誤認成「商店全開」：商品仍然跟劇情進度走。
CH3

紙上英雄

舞台：提亞納營地｜頭目：巨角（Silver Horn）
前往營地→麥西摩加入→避開高速敵人區→巨角戰
  • 這章開始多注意分岔房間，主路旁的小門常放道具。
  • 章後可開始留意提亞納相關派遣，後面隱藏內容會用到這區的鑰匙。
CH4

高迪爾研究所

舞台：高迪爾研究所｜重點角色：瑪莉諾、席娜蒙
研究所探索→瑪莉諾／席娜蒙劇情→賽克博士→連續頭目
  • 開始有更多 FM 與角色專屬玩法，這章後建議把每個新角色的裝備頁都看一次。
  • 看到新派遣就先派，不要堆著；100% 最常漏的就是派遣資料與素材。
CH5

獵人聯手

舞台：烏魯工廠｜重點：艾克賽爾登場
工廠→艾克賽爾→傑洛再登場→紳士戰
  • 從 CH5 起，派遣可能挖到後期非常有用的X 反轉類 FM。
  • 如果你要「能收就收」，這時開始把派遣當主線的一部分。
CH6

友情的意義

舞台：吉米亞拉礦山｜頭目：安榭塔斯
礦山探索→傑洛／夏德劇情→安榭塔斯→重大劇情
  • 地圖偏長，善用你的「遇敵開關」：探索時關、想刷掉落時再開。
  • 派遣仍要收，後期材料與資料會從這裡補。
CH7

攻擊基地台！

舞台：巴拿利亞沙漠｜頭目：波羅克
流沙區→能源管判讀→鏡面雷射機關→3F 頭目
  • 流沙：看能源管百分比，找零頭的管線方向前進。
  • 鏡子機關：先轉後方路線的鏡子，再處理前面的，避免雷射誤射敵人裝置。
  • CH7 派遣能取得後期重要 FM；進 CH10 前最好確認有沒有拿到完全反制類的重要品。
CH8

終極武器

舞台：梅爾達礦石工廠｜頭目：波羅克、費拉姆
礦石工廠→波羅克戰→費拉姆戰→超 FM 劇情
  • 這章後開始進入終盤，沒撿完的舊區域可以用傳送回去整理。
  • 梅爾達相關秘密鑰匙會關係到 Zero 的隱藏型態，記得看「隱藏內容」頁。
CH9

決戰時刻

舞台：墓地遺跡基地／中央塔｜重點頭目：刀疤鐵面、伊普西隆
基地遭襲→刀疤鐵面→反攻→伊普西隆
  • 刀疤鐵面會針對同類型攻擊做防護，正常玩法要射擊／格鬥交替。
  • 你雖然數值很高，還是建議留意 Boss 機制，這樣重玩不會變純看動畫。
CH10

在正義的名義下

最終章｜原名：In The Name Of JUSTICE
重要：去停機坪後就是一連串劇情，先把該買、該收、該派遣的東西處理完。
  • 進終章前先確認 CH5～7 派遣的 X 反轉類 FM、CH7 的完全反制。
  • 空中都市商店可補後期武器，例如傑洛三屬性「+」劍、艾克賽爾雙槍 III 等。
  • 有興趣可刷「噴油槍」；正常掉率非常低，但對無屬性弱點的頭目很有用。
  • 最終戰完成後一定要存 Clear Data，不然破關後封印區不會正式進入你的收集流程。

100% 收集檢查表

你的舊檔判讀：公仔畫面出現「NEW」代表已經取得、只是還沒點開看；沒有 NEW 的格子是你已經閱覽過，不是缺少。

影片／資料容易漏在哪

很多影片不是主線自動給，而是派遣取得。例如中央塔、提亞納營地、研究所、烏魯工廠、礦山、沙漠等區都有派遣對應內容。破關後還有中央塔隱藏房間與最終影片。

如果你的舊檔真的約 98%，最後 2% 很可能就在派遣資料、公仔未檢查、秘密區掉落或極低機率副武器，而不是漏掉整段大型劇情。

X

終極鎧甲

提亞納鑰匙 → 回提亞納營地秘密區 → 擊敗拉芙蕾西亞 → 取得 X 的強力隱藏 Hyper。

原名：Ultimate Armor / Rafflesian

ZERO

絕對零度

梅爾達鑰匙 → 梅爾達礦石工廠秘密區 → 擊敗鴨嘴獸系隱藏頭目 → 取得你說的「翅膀惡魔傑洛」。

原名：Absolute Zero / Duckbill Mole

特別封印區與九尾一族

破關→Clear Data→中央鑰匙→中央塔底層封印門→一尾～九尾

八尾後還會進一步碰到最終公仔機。這裡不是普通「二周目附贈」，而是整個遊戲最後一大塊收集區。

秘密商店

拉格廢墟隱藏區的三位商人：Cumin／Jasmine／Saffron。你記得的「第一關頂樓、三個商人、貓爪」就是這套。

公仔機位置

  • 第 1 台：東廣場，空中巴士出發口後的主要走廊。
  • 第 2 台：南廣場，進中央塔後第二條走廊。
  • 第 3 台：特別封印區，擊敗八尾後的左側路線。
你的目標：不怕死、不缺錢、不用練等；但武器、FM、公仔、商店、劇情照正常取得。

推薦開啟

EXP 最大第一次戰鬥會從 Lv.1 一路跑升級動畫到 Lv.99，所以會卡一下；你已經實測成功。

檔名：SLPM-65643_2AF40F67.pnach

不建議常駐

  • 速度 999：很可能變成敵人幾乎沒有行動機會，戰鬥機制直接消失。
  • 火／冰／雷全吸收：會把屬性戰鬥玩壞，不符合你「可以打但不想死」的需求。
  • 全公仔／全收藏：你想自己收，所以別開。
  • 強制全角色：會破壞正常劇情入隊節奏，所以別開。
