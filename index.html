你這次的玩法

角色一入隊就是高等大佬，但劇情、商店、武器、FM、公仔、寶箱都照正常流程自己拿。不開全武器、不強制全角色。

最重要的習慣

每破一章都回基地：商店看新貨 → 派遣收結果 → 補 FM → 再進下一章。很多 100% 漏項不是藏在迷宮，而是漏掉章節更新。

破關不等於結束

破關後拿中央鑰匙，才會開放特別封印區與一尾～九尾。你以前打完九尾，這次可以直接用清單確認有沒有漏收。

CH1 詳細版

第一章：潛入基坎提斯／拉格拉諾廢墟

這一章先照地圖看樓層。藍色資料晶體要用衝刺撞，終端機則直接調查。

整章主線：起點 → 1F 西側終端機 → 第一批膠囊 → 第二批膠囊 → 與傑洛同步解除 3F 鎖 → 強制戰 → 與傑洛會合 → 河馬型頭目 → 影子背叛事件。
起點先進正前方的門。
到第一個岔路後，往右走。右側會連續看到兩個房間。
第一個右側房間是儲存點。
要不要存都可以；從房間出來後，繼續進右邊下一間。
1F 西側：調查終端機解除第一道安全鎖。
調查電腦／控制台後，1F 西側門鎖解除，接著會收到傑洛的第一次通訊。他會告訴你還有其他安全系統要解除。
回走廊先把兩顆藍色資料晶體撞掉。
可拿：50 Zenny、LE 強化類道具。
藍色晶體不是按調查，要用衝刺撞上去。
穿過剛解除的門，走樓梯到下一層。
岔路附近有一顆黃色資料晶體。黃色晶體是補充型資料，如果你現在 LE／能源槽是滿的，可能拿不起來。
進第一個膠囊房，把裡面的膠囊全部調查。
不要只碰一個。全部看過後會觸發傑洛第二次通訊，並開放下一段路線。
先不要急著走主路，搜膠囊房外的兩個側房。
可拿：解除鎖定程式、30 Zenny、70 Zenny。
再走下一段樓梯，先拿路上的黃色補充資料，再進第二個膠囊房。
第二批膠囊一樣全部調查，完成後傑洛會再通訊。
離開第二個膠囊房後，去右邊的兩個房間。
其中一間有溶解飛彈；另一間就是這章最容易卡住的同步終端機。
同步終端機：看傑洛的節奏，第三次亮起時按 ○。
畫面／提示會連續閃動並有節奏聲。重點不是狂按，等到第三次提示的節奏點再按 ○，讓艾克斯和傑洛同時啟動。成功後會解除 3F 西側 的安全鎖。失敗就重新調查再來一次。
同步成功後準備離開房間，會強制進戰鬥。
敵人只是一般普雷翁追蹤型。打完會正式拿到 Force Metal 系統相關獎勵。
記得把 X 心臟、LE+100 類 FM 裝上；你現在開金手指雖然不怕死，但這些仍算正常收集。
走剛打開的門進樓梯間。
門邊有能源槽補充資料。上樓後先不要直接進中央那扇門，先沿走廊走到底搜刮。
頭目前最後搜刮。
可拿：護盾強化類道具、備份程式、全能源槽補充；附近也有儲存點。
你會看到一扇目前打不開的門，先記位置。之後取得拉格拉諾鑰匙回來，這裡會通往秘密區／秘密商店。
回到剛才略過的中央門，進去和傑洛會合。
接著直接進第一章頭目戰：河馬型大型機械。你現在 Lv.99＋高能力值基本不會翻車，重點是別漏戰後道具。
打完頭目不要急著走。
先往前拿力量+1、速度+1，離開房間後再撞紫色資料晶體拿能源槽零件，旁邊還有 80 Zenny。
再往上一層，右側角落拿疫苗程式＋重新啟動程式。
全部拿完後，再進中央門。接著就是影子帶伊普西隆出現 → 影子背叛 → 傑洛被打落 → 艾克斯逃離的劇情，第一章結束。
第一章完成前你應該確認：兩批膠囊都調查、同步終端機成功、X 心臟／LE+100 拿到、頭目前側房搜完、頭目後力量+1／速度+1／能源槽零件拿完。
CH2

第二章：奪回中央塔

這章先以地圖走中央塔；記得和路上的居民對話、搜側道。主線完成後基地、商店街、傳送與後續收集功能才正式展開。

CH3

第三章：紙上英雄

提亞納營地開始有巡邏機器視線機關；被照到會送回區域起點。先走凹槽躲視線，把支線房與道具拿乾淨，再推主線。

CH4

第四章：高迪爾研究所

這章開始正式接觸席娜蒙與 FM 生成。研究所岔路多，請直接對照地圖把兩側走廊與升降機房都搜完，不要只跟著主門走。

CH5

第五章：獵人聯手

烏魯工廠有浮游警戒機，碰到就強制戰。想收集就對照地圖繞過視線先拿角落道具，再繼續追蹤傑洛。

CH6

第六章：友情的意義

吉米亞拉礦山中途會取得能破壞巨石的強化零件。拿到後不要只往前，記得回頭把先前被石頭擋住的支線與道具補掉。

CH7

第七章：攻擊基地台

流沙區：調查能源管，找百分比不是整十的管線方向；也可以直接照地圖去劇情點。掉進基地後，B1 先拿閘門道具 → 1F 先解左上雷射鏡 → 2F 左上開終端 → 回 1F 解另外三房鏡子 → 再回 2F 開另外三個終端 → 3F 頭目。

CH8

第八章：終極武器

梅爾達礦石工廠入口外先繞右後方找派遣機械與道具；入口那扇現在鎖住的門要記住，日後取得梅爾達鑰匙就是回這裡拿傑洛隱藏型態。

CH9

第九章：決戰時刻

警報柱：碰柱觸發戰鬥，戰後顏色會由藍→黃→紅；要在任一柱恢復紅色前把該區全開並衝過門。
旋轉房拿全道具：左×2 → 右×1 → 左×1 → 右×2 → 左×1 → 右×2。

CH10

第十章：在正義的名義下

前往停機坪前先整理。停機坪之後會連續推進劇情；先收派遣結果、買武器、拿隱藏型態。最終區遇到連續傳送頭目房時，進去後要打完該場才能退出。

100% 收集檢查表

你的舊檔判讀：公仔畫面出現「NEW」代表已經取得、只是還沒點開看；沒有 NEW 的格子是你已經閱覽過，不是缺少。

影片／資料容易漏在哪

很多影片不是主線自動給，而是派遣取得。例如中央塔、提亞納營地、研究所、烏魯工廠、礦山、沙漠等區都有派遣對應內容。破關後還有中央塔隱藏房間與最終影片。

如果你的舊檔真的約 98%，最後 2% 很可能就在派遣資料、公仔未檢查、秘密區掉落或極低機率副武器，而不是漏掉整段大型劇情。

X

終極鎧甲

提亞納鑰匙 → 回提亞納營地秘密區 → 擊敗拉芙蕾西亞 → 取得 X 的強力隱藏 Hyper。

原名：Ultimate Armor / Rafflesian

ZERO

絕對零度

梅爾達鑰匙 → 梅爾達礦石工廠秘密區 → 擊敗鴨嘴獸系隱藏頭目 → 取得你說的「翅膀惡魔傑洛」。

原名：Absolute Zero / Duckbill Mole

特別封印區與九尾一族

破關→Clear Data→中央鑰匙→中央塔底層封印門→一尾～九尾

八尾後還會進一步碰到最終公仔機。這裡不是普通「二周目附贈」，而是整個遊戲最後一大塊收集區。

秘密商店

拉格廢墟隱藏區的三位商人：Cumin／Jasmine／Saffron。你記得的「第一關頂樓、三個商人、貓爪」就是這套。

公仔機位置

  • 第 1 台：東廣場，空中巴士出發口後的主要走廊。
  • 第 2 台：南廣場，進中央塔後第二條走廊。
  • 第 3 台：特別封印區，擊敗八尾後的左側路線。
你的目標：不怕死、不缺錢、不用練等；但武器、FM、公仔、商店、劇情照正常取得。

推薦開啟

EXP 最大第一次戰鬥會從 Lv.1 一路跑升級動畫到 Lv.99，所以會卡一下；你已經實測成功。

不建議常駐

  • 速度 999：很可能變成敵人幾乎沒有行動機會，戰鬥機制直接消失。
  • 火／冰／雷全吸收：會把屬性戰鬥玩壞，不符合你「可以打但不想死」的需求。
  • 全公仔／全收藏：你想自己收，所以別開。
  • 強制全角色：會破壞正常劇情入隊節奏，所以別開。
