第五章大區塊順序圖（非比例地圖）

出發前：基地主城準備

和奈奈（ナナ／Nana）、首領 R（チーフR）對話，從新希望基地傳送至烏魯工廠（ウルファト生産工場）。劇情目標是追查傑洛（ゼロ／Zero）。
商店此章可購入：瑪莉諾的光束環刃（ビームチャクラム，3300Z）、席娜蒙的金屬拳套（メタルボクサー，3100Z）、麥西摩的破壞鐵鎚（Crash Hammer，3500Z），史派達的黑桃 K／梅花 K（各 2800Z）。原日文裝備名未核實的項目先保留英文對照。
能力 999 的情況下，可以讓瑪莉諾（マリノ／Marino）留隊負責偷道具；席娜蒙（シナモン／Cinnamon）可試新武器。此建議並非強制隊伍配置。

01｜工廠入口與熔爐 1

進入工廠，聽到警報聲後碰到漂浮哨戒無人機；被其發現會觸發戰鬥。先拿角落的火焰防護（Fire Guard）與公仔代幣（フィギュアコイン）。
穿門並由北門走向第一座熔爐（Smelting Furnace 1）。繞去對面拿 300 FME、1000Z，找到可派遣的搬運機械兵（ラッシュローダー メカニロイド），務必調查。
回前一扇門改走另一條路，回收生命增強（ビルドLE）、フィギュアコイン、極限冰凍（ドメガブリザード）；下一步進右門前往第二熔爐。

02｜熔爐 2、熔爐 3 與暫時不能回收的機械兵

安全室躲開哨戒機器，先搜邊角的 タンクパーツ、フィギュアコイン；走唯一沒有封鎖的門，取得 フィギュアコイン、タンクエナジー50、ビルドWE。
從入口左邊通道繞第二熔爐，下一條廊道能看到 アインハンマー 機械兵。目前不能收回：需在第七章巴拿利亞大沙漠 B1 紅色閘門取得ハンマー鉄球（ハンマー鉄球／鐵槌球）。→ 詳細取得方法與回頭修復攻略，先在清單保留未完成。
同一區域先拿史派達（スパイダー／Spider）用的紅心 K（King of Hearts），再回先前安全室，這次選左門取得 800Z，通往第三熔爐。
第三熔爐沒有哨戒機器；繞背側拿 ビルドスピード。過門立即左轉取 スピードアップ，再進下一道門，取艾克斯（エックス／X）的空中破壞砲（Aero Buster）與迷你電池（プチバッテリー）。

03｜艾克賽爾加入、貨運區入口

回上一房間，繞箱堆前進觸發事件：保全機器人現出真面目，原來是艾克賽爾（アクセル／Axl）。劇情後他加入隊伍。
再繞另一批箱子取得 タンクエナジー50。穿下扇門看見儲存點；存檔後進入貨運區（Freight Area），沿停止的輸送帶走，左轉進「零件進貨線（Parts Intake Line）」。

04｜進貨線：第一段輸送帶，照方向走

重點修正：舊版只寫「切換後沿新方向走」不夠。以下方向依 台灣《洛克人回憶之館》CH5 路線整理。方向是攻略地圖的上下左右，不是鍵盤必須一直按住相同方向；角色走到下一個實際岔口時再判斷。
先認區域：零件進貨線（Parts Intake Line）是第一段帶控制台的區域，入口會有需要強制戰鬥的普雷翁（プレオン）敵人。和第二段「配送線」不是同一個機關。
第一段核心過關順序：
左 ←　→　上 ↑　→　右 →　→　切換輸送帶方向　→　左 ←　→　左 ←　→　上 ↑
這是主線到出口的路徑。若要拿沿路道具，先在岔口繞到寶箱再回主線，別把為了拿寶箱走的支線方向當作必經步驟。
入口先拾取 1000Z，途中固定戰包含 プレオン Gunner（普雷翁槍手）和 プレオン Soldier（普雷翁士兵）；別漏 タンクエナジー25、ゲインHYPER 和 WE +5。
出現切換控制台時：互動一次讓輸送帶改向，再按上方後半段「左 → 左 → 上」繼續走，直到進入第二段配送線。

05｜配送線：第二段輸送帶與兩次改向

第二段別用第一段的路線！照日文遊戲內的輸送帶方向走；遇到閃亮的切換控制台才進行「變換方向」。
第二段核心過關順序：
上 ↑　→　右 →　→　右 →　→　上 ↑
第一次切換方向
左 ←　→　上 ↑　→　左 ←
第二次切換方向
右 →　→　下 ↓　→　右 →　→　上 ↑　→　右 →　→　上 ↑
與「先轉左再找出口」不同，這裡有兩個控制台切換點，必須先後按順序操作。
收集路線與直達路線不同：本道有多枚模型硬幣（フィギュアトークン／フィギュアコイン）、固定戰、強化道具；收集支線需先繞去拿到寶物，再返回切換台跟上面的直達路線。不用因為拿寶箱偏離主路就重新開始。
普雷翁護士（プレオン Nurse）特殊事件：與 プレオン Soldier、プレオン Shielder 同時出現時，可以先打其他敵人，把 Nurse 留到最後。護士可能幫我方回復 LE 後逃走；這是正常機制，也涉及席娜蒙後續的「病毒注射器」掉落機率。別因為她逃跑就判定這場出錯。
檢查：確認兩處切換台都操作、沿路戰鬥通過、可見的 フィギュアコイン 都拿到，再從終點出口進貨運升降區。

路線與機關操作對照 RMMH 第五話（主線＋輸送帶解法），再與 GameFAQs PS2 逐區攻略比較；尚未提供的實機俯視圖不會假冒成精確方位地圖。

06｜貨運電梯、傑洛重新歸隊

先搭第一座貨運電梯，上去調查可回收的殺手螳螂機械兵（キラーマンティス メカニロイド）。倒下的警衛中，右邊一名可搜 Fire Guard，左邊第二名可搜 Ice Missile。
進電腦室（Computer Room）搜 ビルドシールド、ビルドアーマー、Hunter Missile。此處可選擇回基地整理裝備。
重要：接下來傑洛的裝備狀態會受到劇情限制，到第六章發生相關劇情後才能重新更換。進第二台電梯前，務必先整理其他隊員裝備與 FM。從電腦室左門搭第二座貨運電梯，進長走廊觸發傑洛與敵方幹部交戰劇情。艾克斯與艾克賽爾趕到後，傑洛（ゼロ／Zero）正式歸隊。
先轉身拾取 バックアップ、ビルドパワー，再回電腦室走另一條新的通道，拿 タンクエナジー100 ×2 和 ゲインHYPER，之後進 Boss 門。

07｜Boss：馬赫紳士（マッハ・ジェントラー／マッハジェントラー）

Boss 等級 42、LE 28000，屬性為火；會吸收火傷害，水屬傷害是 150%。別用 X Fire 的一般火屬攻擊。
可以用艾克賽爾 DNA Change 變身銀角（シルバーホーンド），施放 Tidal Wave 把空中 Boss 擊落；配合傑洛與艾克斯集中攻擊。注意要在己方後續連續回合多時擊落才不會剛落地就重新起飛。
他會呼叫 プレオン Nurse 回血；護士出現時優先處理，避免 Boss 血量被補回。馬赫傑特拉可偷 Twin Fire（100%）或 タンクエナジー100（50%），擊破固定獲得 Fire Buster MKII、サブタンク。

08｜Boss 之後還有四連戰

打完馬赫傑特拉（マッハジェントラー）還不能離開；Duboar 主機會讓工廠進入緊急量產模式，隊伍 LE 會先補滿。
第 1 戰：追擊型 プレオン（プレオン Chaser）×2＋火花型（プレオン Spark）×2。
第 2 戰：プレオン Spark ×2＋防盾型（プレオン Shielder）×2。
第 3 戰：混合型（プレオン Hybrid）×1、防盾型（プレオン Shield）×1、プレオン Chaser ×1、狂暴 プレオン Spark ×1。
第 4 戰：狂暴 プレオン Hybrid ×4。打完看艾克賽爾變身阻止電腦的劇情，返回新希望基地。

09｜回基地：下一章前不要忘記

傑洛和艾克斯對新隊友產生意見分歧，會暫時獨自行動。這是正常劇情，不是你走錯。
第五章拿到 プチバッテリー 後，可以回提亞納營地（ティアナ海底収容所）回收 ガルプファー メカニロイド；第二熔爐的 アインハンマー（Einhammer） 需先到 CH7 巴拿利亞大沙漠 B1 紅色閘門取回 ハンマー鉄球，再回來修復。
先確認烏魯工廠新取得的兩隻可派遣機械兵、全部公仔代幣，以及新解鎖的派遣內容，再找奈奈（ナナ）開啟第六章。
